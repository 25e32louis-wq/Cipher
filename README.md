# CIPHER — Build the Signal

Premium single-page CIPHER / SJEC student association website foundation for the 2nd-year Design Hackathon.

## Run locally

Open `index.html` with VS Code + Live Server.

## Structure

- `index.html` — one continuous page with Home / About / Events / Team / Join sections.
- `styles.css` — visual system and responsive layouts.
- `app.js` — typewriter hero, smooth navigation, active section state, filters, search, event drawers, team profile drawers, mobile menu and form validation.
- `assets/sjec-campus.png` — supplied SJEC campus image.
- `assets/sjec-25-years.png` — supplied SJEC 25 Years of Excellence emblem.
- `scripts/cipher_core_blender.py` — starting point for the future Blender 3D asset.

## Design notes

Palette: #07080B / #14171D / #F4F1EA / #9CA2AD / #EF5147 / #D7AD68.

The CIPHER Core is intentionally built as a replaceable visual container. A future Blender `.glb` can be inserted without changing the page composition.
